# Headshot x store (Flask + SQLite) — ร้านขายไฟล์โค้ด

แอดมินอัปโหลดไฟล์อะไรก็ได้เข้าสินค้า (.js .css .py .cpp .json .zip ฯลฯ) ลูกค้าโอนตาม QR/เลขบัญชีที่ร้านตั้งไว้ แนบสลิป
แอดมินอนุมัติแล้วลูกค้าโหลดไฟล์ได้จากหน้าออเดอร์ (โหลดทีละไฟล์หรือทั้งหมดเป็น .zip) ไม่มีการส่งข้อความรหัสแล้ว

## รันบนเครื่อง
```bash
pip install -r requirements.txt
export ADMIN_PASSWORD="ตั้งรหัสยาวๆ"      # ต้องตั้ง ไม่งั้นเข้าหลังบ้านไม่ได้
export PROMPTPAY_ID="0812345678"          # เบอร์ 10 หลัก / เลขบัตร ปชช. 13 หลัก / e-Wallet ID 15 หลัก (TrueMoney)
python app.py seed                        # (ครั้งแรก) ใส่สินค้าตัวอย่าง 4 ชิ้นพร้อมไฟล์จริง
python app.py                             # เปิด http://localhost:5000
```
- หน้าร้าน `/` · หลังบ้าน `/admin` (Windows PowerShell ใช้ `$env:ADMIN_PASSWORD="..."`)
- ถ้าเคยใช้เวอร์ชันเก่า (แบบข้อความรหัส) ให้ลบไฟล์ `shop.db` ก่อน เพราะโครงฐานข้อมูลเปลี่ยน

## วิธีเพิ่มสินค้า (หลังบ้าน)
1. หัวข้อ "เพิ่มสินค้าใหม่": ใส่ชื่อ ราคา คำอธิบาย และ "หมวด / ภาษา" ซึ่งเป็นช่องพิมพ์เอง ข้อความที่พิมพ์จะขึ้นเป็นตัวอักษรใหญ่บนหน้าปกสินค้า (เช่น PYTHON, JS, C++, BOT) และกลายเป็นปุ่มกรองหน้าร้านอัตโนมัติ
2. ช่อง "เพิ่มไฟล์" เลือกได้หลายไฟล์พร้อมกัน ทุกนามสกุล แล้วกดเพิ่มสินค้า
3. เพิ่ม/ลบไฟล์ทีหลังได้ที่การ์ดของสินค้านั้น สินค้าที่ยังไม่มีไฟล์จะไม่แสดงหน้าร้าน
4. "จำกัดจำนวน" ใส่เมื่อจะขายแบบจำกัดชุด เว้นว่างคือขายไม่จำกัด
5. "โค้ดตัวอย่างโชว์หน้าร้าน" ใส่ส่วนสั้นๆ ไว้โชว์ลูกค้า ส่วนไฟล์จริงลูกค้าจะเห็นเฉพาะชื่อและขนาดก่อนซื้อ

## ตั้งช่องทางรับเงิน (หลังบ้าน > ช่องทางรับเงิน)
- อัปโหลดรูป QR ของคุณเอง (JPG/PNG/WEBP ไม่เกิน 6MB) และกรอกธนาคาร เลขบัญชี ชื่อบัญชี ระบบจะแสดงข้างกันในหน้าออเดอร์ มีปุ่มคัดลอกยอดและเลขบัญชี
- QR ที่อัปโหลดมักไม่มียอดเงินฝังมา ระบบจึงโชว์ "ยอดที่ต้องโอน" ตัวใหญ่ให้ลูกค้ากรอกเอง เวลาอนุมัติให้เทียบยอดในสลิปกับออเดอร์ทุกครั้ง
- ถ้าไม่อัปโหลด QR และตั้ง `PROMPTPAY_ID` ไว้ ระบบจะสร้าง QR พร้อมเพย์พร้อมยอดให้แทน (ตัวสำรอง) ถ้าอัปโหลดแล้วจะใช้รูปที่อัปโหลดก่อนเสมอ

## ขั้นตอนของลูกค้า
เลือกสินค้า > สั่งซื้อ > หน้าออเดอร์แสดง QR พร้อมเพย์ยอดตรงบิล > แนบสลิป > แอดมินเทียบสลิปกับแอปธนาคารแล้วกด "อนุมัติ" > ลูกค้าโหลดไฟล์ได้

## ตั้งค่า (environment variable)
| ชื่อ | ความหมาย |
|---|---|
| ADMIN_PASSWORD | รหัสเข้าหลังบ้าน (จำเป็น) |
| PROMPTPAY_ID | (ไม่บังคับ) ตัวสำรองเมื่อไม่ได้อัปโหลด QR: เบอร์ 10 หลัก, เลขบัตร ปชช. 13 หลัก หรือ e-Wallet ID 15 หลัก |
| SHOP_NAME | ชื่อร้าน (ค่าเริ่มต้น Headshot x store) ตัว x ตรงกลางจะถูกไฮไลต์ในโลโก้ |
| HOLD_MINUTES | เวลารอชำระต่อออเดอร์ (นาที, ค่าเริ่มต้น 30) |
| MAX_UPLOAD_MB | ขนาดอัปโหลดสูงสุดต่อครั้งของแอดมิน (ค่าเริ่มต้น 200) |
| SECRET_KEY | คีย์ session (ไม่ตั้งจะสร้างไฟล์ .secret_key ให้) |
| SECURE_COOKIES | ตั้งเป็น 1 เมื่อใช้ HTTPS |
| BEHIND_PROXY | ตั้งเป็น 1 เมื่อรันหลัง cloudflared/nginx เพื่อให้ตัวจำกัดจำนวนครั้งแยกลูกค้าตาม IP จริง (อย่าเปิดถ้าเปิดพอร์ตตรงสู่เน็ต) |
| DB_PATH, UPLOAD_DIR | ที่เก็บฐานข้อมูลและไฟล์ |

## ใช้ TrueMoney Wallet รับเงิน
- ตั้ง `PROMPTPAY_ID` เป็นเลข e-Wallet ID 15 หลักของบัญชี TrueMoney ระบบจะสร้าง QR แบบ e-Wallet ให้อัตโนมัติ
- ถ้าผูกเบอร์โทรของ TrueMoney เป็นพร้อมเพย์ไว้แล้ว จะใช้เบอร์ 10 หลักก็ได้
- ก่อนเปิดขายจริง ลองสแกน QR จากแอปธนาคารอื่นโอนยอดเล็กๆ (เช่น 1 บาท) เพื่อเช็กว่าเงินเข้าจริง

## เปิดสู่เน็ตด้วย Cloudflare Tunnel (ทดลอง)
```bash
export ADMIN_PASSWORD="รหัสยาวๆ"
export PROMPTPAY_ID="เลขที่รับเงิน"
export SECURE_COOKIES=1
export BEHIND_PROXY=1
python app.py &
sleep 2
cloudflared tunnel --url http://localhost:5000
```
ใช้ `http://` ไม่ใช่ `https://` เพราะ Flask เปิดแบบ HTTP ธรรมดา (Cloudflare ทำ HTTPS ให้ฝั่งหน้าเว็บ) ลิงก์ที่ได้เปลี่ยนทุกครั้งที่รันใหม่
หยุด: กด Ctrl+C แล้วพิมพ์ `kill %1`

## ขึ้นเซิร์ฟเวอร์จริง
```bash
gunicorn -w 2 -b 127.0.0.1:8000 app:app
```
- วางหลัง nginx/Caddy ที่เปิด HTTPS แล้วตั้ง SECURE_COOKIES=1
- ถ้าใช้ nginx ให้ตั้ง `client_max_body_size` ให้เท่ากับ MAX_UPLOAD_MB
- สำรอง `shop.db` และโฟลเดอร์ `uploads/` เป็นประจำ (ไฟล์สินค้าทั้งหมดอยู่ในนั้น)

## ความปลอดภัยที่ใส่ไว้
- ไฟล์สินค้าเก็บด้วยชื่อสุ่ม ไม่เปิดเป็นไฟล์สาธารณะ โหลดได้เฉพาะออเดอร์ที่ชำระแล้วและเฉพาะไฟล์ของสินค้าในออเดอร์นั้น
- ส่งไฟล์แบบ attachment เสมอ (ไฟล์ .html ที่อัปโหลดจะไม่ถูกรันบนโดเมนร้าน)
- ลิงก์ออเดอร์เป็นลิงก์ลับ มี CSRF ในหลังบ้าน จำกัดการลองรหัสผ่านและการสั่งถี่ๆ ตรวจสลิปว่าเป็นรูปจริง
- ยังไม่ได้ต่อ API ตรวจสลิปอัตโนมัติ แอดมินต้องเทียบยอดและเวลาในแอปธนาคารเองทุกครั้ง ระวังสลิปปลอม

## ข้อควรรู้
- ขายเฉพาะโค้ดที่คุณเขียนเองหรือมีสิทธิ์ขาย ถ้าเป็นโค้ดโอเพนซอร์สให้ดูเงื่อนไขไลเซนส์ก่อน
- ลูกค้าที่จ่ายแล้วโหลดซ้ำได้ตลอดจนกว่าแอดมินจะลบไฟล์
